# Competitive UI Matrix

## Apple Fitness+
- Strengths: calm confidence, single focus per screen, metrics integrated without clutter, strong hierarchy.
- Learnings for AuraFitness: daily summary should feel composed; recommendations should feel earned, not noisy.
- Avoid copying: overly platform-specific chrome or ornamental glass as the main identity.

## Strava
- Strengths: strong action hierarchy, activity-first discovery, clear route/training labels, social proof tied to real behavior.
- Learnings for AuraFitness: workouts should separate discovery, saved state, and progress cleanly.
- Avoid copying: aggressive performance language when the product is also about nutrition and habits.

## Lifesum
- Strengths: friendly but trustworthy nutrition framing, easier logging story, good separation of logging vs understanding.
- Learnings for AuraFitness: nutrition flow should prioritize fast capture first, macro interpretation second.
- Avoid copying: lifestyle-marketing tone in core product surfaces.

## Google / Material
- Strengths: strong semantic system, predictable touch targets, good density control.
- Learnings for AuraFitness: shared tokens and semantic component APIs matter more than one-off page polish.
- Avoid copying: generic enterprise blandness.

## Uber / Base
- Strengths: disciplined systems, clear contrast, product-first surfaces, accessibility-minded component behavior.
- Learnings for AuraFitness: navigation, list rows, and settings should read as product infrastructure, not decoration.

## Canva
- Strengths: approachable but intentional visual energy, strong action framing.
- Learnings for AuraFitness: use warmth to invite action, but keep the work surfaces clean.
- Avoid copying: feature-broadcasting density in health workflows.
